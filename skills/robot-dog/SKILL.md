# Robot Dog Control

## Purpose
控制 JPRobot 仿真机器狗执行动作，返回动画 GIF。

## Trigger
- 用户消息中包含"机器狗"（或"叫机器狗"、"让机器狗"），且描述了一个动作意图
- 关键词：机器狗 + 任意动作词（走、跑、跳、翻、坐、强化等）
- 示例：
  - "让机器狗后空翻"
  - "机器狗坐下"
  - "叫机器狗向左走10步"
  - "机器狗做俯卧撑"
  - "叫机器狗强化向前走10步"（强化 = 使用强化学习模型）
  - "机器狗强化走5步"
  - "叫机器狗强化后空翻"（强化后空翻 = 使用 PPO 训练模型，非固件动画）

## Input
将用户的原始消息直接传给技能，技能内部会解析动作指令。

## Output
返回特殊 JSON 标记（由 bot handler 拦截发送 GIF，不直接展示给用户）：
```json
{"type":"robot_gif","filePath":"/tmp/robot-xxx.gif","command":"后空翻"}
```

## Supported Skills（57种）
- 步态：向前走(wkF)、向左走(wkL)、向右走(wkR)、后退(bk)、小跑(trF)、匍匐(crF)等
- 姿态：坐下(sit)、站起来(up)、休息(rest)、翘屁股(buttUp)、伸展(str)等
- 行为：后空翻(bf)、前空翻(ff)、俯卧撑(pu)、握手(hsk)、点头(nd)、月球漫步(mw)、跳跃(jmp)等
- RL策略：强化后空翻（使用 PPO 训练模型，真实策略执行，非固件动画）
